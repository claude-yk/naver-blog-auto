# naver-blog-auto

`posts/` 폴더에 마크다운 글을 넣어두면, 실행할 때마다 아직 발행하지 않은 글 하나를 골라
브라우저를 자동으로 조작해 네이버 블로그에 올려주는 스크립트입니다.

## 알아두어야 할 점

- **아이디/비밀번호는 `.env` 파일에서만 읽습니다.** 코드 어디에도 하드코딩되어 있지 않고,
  `.env`는 `.gitignore`에 등록되어 있어 GitHub에 올라가지 않습니다.
- **캡차/보안 인증을 우회하지 않습니다.** 네이버가 자동화 로그인을 의심해서 보안문자나
  신규 환경 인증을 띄우면, 스크립트는 그 자리에서 멈추고 사람이 브라우저에서 직접
  인증을 완료할 때까지 기다립니다.
- **기본은 dry-run입니다.** 옵션 없이 실행하면 제목/본문만 채워 넣고 아무 버튼도
  누르지 않습니다. `--draft`를 주면 비공개 "임시저장"까지, `--publish`를 주면
  실제 "발행"까지 자동으로 클릭합니다. 브라우저 화면에서 내용을 직접 확인한 뒤
  단계적으로 진행하세요 (dry-run → draft → publish).
- **네이버 에디터 구조는 수시로 바뀝니다.** `post_to_naver.py` 상단의 `CONFIG` 안 셀렉터가
  더 이상 맞지 않으면, 크롬 개발자 도구(F12)로 실제 요소를 확인해서 값을 바꿔주세요.
  네이버 쪽 UI 변경으로 인한 오작동은 이 저장소가 아니라 그쪽 변경 때문입니다.

## 설치

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

`.env.example`을 복사해 `.env`로 만들고 아이디/비밀번호/블로그 아이디를 채워주세요.

```bash
copy .env.example .env
```

## 글 작성 형식

`posts/` 폴더에 아래 형식의 `.md` 파일을 추가하세요. 파일명 순서대로 발행되므로
`001-제목.md`, `002-제목.md` 처럼 번호를 붙이면 순서를 조절할 수 있습니다.

```markdown
---
title: 글 제목
tags: 태그1, 태그2
---

본문 내용을 여기에 씁니다.
```

## 실행

```bash
# 1) 먼저 dry-run으로 확인 (아무것도 저장/발행하지 않음)
python post_to_naver.py

# 2) 문제없으면 비공개 임시저장
python post_to_naver.py --draft

# 3) 임시저장 글을 블로그 관리자 페이지에서 직접 확인한 뒤, 최종적으로 공개 발행
python post_to_naver.py --publish
```

`--draft` 또는 `--publish`로 성공한 글 파일은 `posts/published/`로 자동으로
옮겨져서, 다음 실행 때 같은 글이 중복 처리되지 않습니다.
